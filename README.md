# 🛡️ MPLAD Guard: Bill Verification Model

> **Smart India Hackathon 2026 - AI Verification Backend**  
> Companion backend to [mplad-guard-frontend](https://github.com/codemasteryash/mplad-guard-frontend). 
> This repository houses the AI-powered bill verification model and contextual anomaly detection engine. It is designed to identify and flag the exploitation of General Financial Rules (GFR) 2017, specifically Rule 154, in public procurement by extracting structured data from handwritten receipts and analyzing transaction behavior.
